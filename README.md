# 番茄待办 · 网页版（PWA）

轻量、离线优先的番茄钟 + 待办应用**网页版**。可安装到手机/桌面主屏幕，离线也能用。

> 在线使用：**https://yes-we-coding.github.io/pomodoro-todo-web/**

## ✨ 功能

### 计时
- 专注 / 短休息 / 长休息，自定义时长
- 自动开始休息 / 专注，长休间隔自定义
- 强提醒（常驻通知 + 响铃），多档提示音（经典三音 / 铃铛 / 木鱼 / 编钟）
- 长休结束专属上扬音效
- 白噪音（雨声 / 咖啡馆 / 森林）与音量调节
- 空闲自动暂停：离开页面自动暂停计时
- 空格 开始/暂停

### 待办
- 分组、优先级、截止日期、子任务、备注
- 标签系统（增删 + 按标签筛选）
- 时间预算：已耗 / 剩余实时显示
- 预估番茄数：计划 vs 实际
- 重复任务：每天 / 每周 / 每月自动重置
- 拖拽排序、拖拽到分组
- 撤销删除（`Ctrl+Z`）

### 统计与报告
- 近 7 / 30 天番茄柱状图、连续打卡
- 近一年专注热力图
- 高效时段分布（24 小时 + 星期）
- 今日专注时间轴
- 中断统计（放弃率、按任务明细）
- 预估准确度
- 日报 / 周报 / 月报
- 🧠 智能总结：自动生成的文字总结，每 10 分钟刷新

### 数据
- 数据保存在浏览器 `localStorage`
- 导出 / 导入 JSON 备份
- 支持"安装到主屏幕"（PWA），离线可用

## 🚀 部署

纯静态站点，无构建步骤：

1. 把本目录所有文件推到 GitHub 仓库
2. Settings → Pages → Source 选 `main` 分支 `/ (root)`
3. 访问 `https://<用户名>.github.io/<仓库名>/`

## 🗂️ 结构

```
.
├── index.html              # 应用本体（单文件，全部逻辑）
├── manifest.webmanifest    # PWA 清单
├── sw.js                   # Service Worker（离线缓存）
├── favicon.ico
├── icon-192.png            # PWA 图标
├── icon-512.png
├── icon-maskable-512.png
└── .nojekyll               # GitHub Pages：跳过 Jekyll
```

## 🔄 与桌面版的关系

本项目由桌面版（[pomodoro-todo](https://github.com/yes-we-coding/pomodoro-todo)）的 `index.html` 适配而来：
- 移除窗口控制 / 托盘相关 UI（迷你模式、最小化、置顶等）
- 数据改用纯 `localStorage`（桌面版以 `data.json` 为权威源）
- 久坐提醒改为浏览器计时器实现
- 新增 PWA 支持与移动端响应式布局

两者数据**互不相通**，可通过 JSON 导入 / 导出手动迁移。
